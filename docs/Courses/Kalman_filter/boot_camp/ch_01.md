#### why use Kalman Filter.

It gets too expensive to directly measure the state of the system. This could be the wind noise and sensor errors which are difficult to directly measure.

we have a state prediction, where we estimate the next state given the current state, the measurable input to the system and the an unmeasurable input (noise) to the system.
        $x_(k+1) = A \cdot x_k + B \cdot u_k + w_k$

Then we have a measurement equation.
        $z_k = C \cdot x_k + D \cdot u_k + v_k$

In a way, kalman filter estimates a system which generates the expected result given the system state.


## 📌 Module 1: Introduction to State Estimation
### 1.1.1 Welcome to the Course
* **Key Concept:** The Kalman Filter is an optimal estimator for linear systems with Gaussian noise.
* **The Goal:** Estimating the "internal state" of a system when we only have noisy, indirect measurements.

!!! info "Why this matters for FPGA/ASIC"
    Kalman filters require matrix inversions and multiplications. Transitioning a Python-based Kalman model to fixed-point RTL is a high-value skill in robotics and aerospace.
